# MEMENTO VisualRef V43B — Real Scene

GitHub/Vercel-ready static application. V43B preserves the V43A.1 shared workflow and adds the first real scene layer:

- Hero `.glb` upload and replacement
- Environment `.glb` upload
- Multiple Prop `.glb` assets
- `.hdr` / HDRI upload with PMREM reflections
- IndexedDB binary persistence across reloads
- non-destructive import correction: auto-normalize, auto-ground, pivot, orientation, correction scale and ground offset
- 3D Start/End Hero transforms: XYZ position, XYZ rotation and uniform scale
- separate Shot Camera and Editor Camera
- OrbitControls, TransformControls, scene grid, bounds, camera and light helpers
- Frame Selected / Frame All
- real Start and End captures generated by the same live renderer
- the same loaded scene in Render, Viewport and Timeline

## Deploy

Upload the contents of this folder to the root of the existing GitHub repository. Vercel requires no build command and no output directory.

Open:

- `/render.html`
- `/viewport.html`
- `/timeline.html`

## Asset workflow

1. Open **Viewport**.
2. Use `+ HERO`, `+ ENV`, `+ PROP`, or `+ HDRI` in Scene Outliner.
3. Select a scene node.
4. Use the viewport gizmo and the Inspector.
5. Correct imported orientation or pivot without modifying the creative Start/End transform.
6. Return to Render or Timeline. The same scene is restored from IndexedDB.

V43B accepts self-contained `.glb` files. External-resource `.gltf` packages are deliberately excluded from this checkpoint.

## External runtime modules

The static pages use an import map pinned to Three.js `0.160.0` and the matching official addons on jsDelivr. When those modules are unavailable, VisualRef retains the visible calibrated Canvas fallback rather than booting to black.
