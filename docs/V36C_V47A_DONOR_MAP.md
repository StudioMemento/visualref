# V36C → V47A Donor Map

V47A does not recreate V36C pixel-for-pixel. It restores the interaction grammar that made V36C immediate while keeping the current scene, asset and Timeline architecture.

| V36C donor principle | V47A implementation | Not carried forward |
|---|---|---|
| One image dominates the workspace | Wider Player, quieter surrounding panels | Four unrelated panels competing with the image |
| “An image is a state; a movement is a delta; a sequence is a curve” | Viewport = State, Render = Delta, Timeline = Curve | Workspace names without a visible product relationship |
| Generation is near playback | Target Δ and Candidate controls in Player and Render | Random generation buried as a secondary utility |
| Start and End remain understandable | Persistent Start / End matrix | Important state hidden inside closed accordions |
| Simple deterministic generation choices | Numeric Target Δ with derived profiles and seeded Candidate | Near / Balanced / Bold as competing primary inputs |
| Immediate A/B reading | Current / Previous / Candidate review | Destructive mutation of the active shot |
| Flat, text-first controls | Reduced cards, borders, duplicate labels and technical filler | Single-file CSS/DOM accumulation |
| White / teal / orange semantic state | Current/shared, Previous, Candidate/End colour cues | Colour as the only state indicator |
| Advanced controls deepen the same concept | Matrix opens existing contextual macro controls | A second contradictory editor |
| Player transport is stable and close to the image | Existing shared Player retained and simplified | Workspace-specific duplicate renderers |

The rule for later V47 work remains:

> Borrow V36C's clarity and muscle memory; do not inherit its accumulated single-file architecture.
