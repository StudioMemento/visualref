# MEMENTO VisualRef V44 — Exact V43B.9 Editor Chip Rollback

V44 keeps the complete GLB, Environment, World/Local gizmo, compensated Pivot and Timeline core. Only the creative option chip was rolled back to the interaction approved in V43B.9.

## Visual contract

- One uninterrupted chip.
- One large, centered, single-line text label.
- Visible left and right chevrons.
- No category icon, option icon, description, `S` / `E` badge, center glyph or visible internal divider inside the option chip.
- Quiet generation-pool exclusion control in the upper-right.

## Invisible interaction zones

The complete chip remains divided into invisible **30 / 40 / 30** hit areas:

- **Left 30%:** assign the option to **START**.
- **Center 40%:** assign the option to **BOTH** Start and End.
- **Right 30%:** assign the option to **END**.

## State language

- **START only:** teal gradient entering from the left.
- **BOTH / same value:** white line on the top and bottom of the complete chip.
- **END only:** orange gradient entering from the right.
- **Neutral:** quiet black chip.
- **Excluded from generation:** dimmed, while remaining available for direct manual assignment.

The hover teaching colors use the same state language. The global Start / Both / End scope remains available for advanced numeric controls, while direct option-chip clicks use their explicit three-zone assignment.
