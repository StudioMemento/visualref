# V47R Release Notes

## Recovery, not another overlay

V47R freezes the V47A experiment and rebuilds the product surface on the native V45 services. It does not continue the MutationObserver and CSS-patch chain.

## Core improvements

- persistent Viewport / Render / Timeline shell;
- one renderer and one loaded Hero across workspace changes;
- world-zero cyclorama and contact-shadow authority;
- one-time asset-specific grounding and editor-camera recovery;
- deterministic Target Delta Candidate generation;
- non-destructive Current / Candidate / Previous review;
- compact World, Delta and Curve surfaces;
- V30-derived Start/End and sequence clarity without V30 runtime inheritance;
- ultrawide and mobile containment;
- automated release gates and acceptance screenshots.

## Deferred from V47R

V47R intentionally does not expand the feature surface. New world types, additional diagnostics, annotation systems and advanced Timeline additions should begin only after the live real-asset acceptance list in `V47R_VALIDATION_REPORT.md` passes.
